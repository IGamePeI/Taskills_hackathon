### API
- Каталог и поиск: фильтрация инструкций по категориям, умный поиск по названию, описанию и тегам.
- Конструктор и форки: создание гайдов с шагами, точечное редактирование шагов, а также возможность сделать форк чужой инструкции.
- Обратная связь и аналитика: комментарии к каждому шагу и статистика для автора.
- Роли и безопасность: разделение на учеников и экспертов, JWT-авторизация на HttpOnly-куках, рейт-лимиты и кэширование в Redis.

### Frontend
- Каталог и просмотр: витрина с популярными гайдами, фильтрация, предпросмотр и пошаговый плеер инструкций.
- Личный кабинет: регистрация, авторизация, управление профилем, отслеживание прогресса прохождения и список своих инструкций.

## Стек

- Backend: Python 3.12, FastAPI, uv, JWT, slowAPI, SQLAlchemy
- Frontend: Vue 3, TypeScript,  Vite, Pinia, SCSS, раздача через Nginx
- Базы данных и кэш: PostgreSQL, PgBouncer, Redis
- Мониторинг: Prometheus, Grafana, Loki, Promtail
- Вспомогателные: docker, docker-compose

## Как запустить

Из корневой папки проекта:

```bash
docker compose up --build
```

После запуска будут доступны:
- Frontend: `http://localhost`
- Swagger UI (документация API): `http://localhost:8090/docs`
- Grafana (дашборды и логи): `http://localhost:3000`
